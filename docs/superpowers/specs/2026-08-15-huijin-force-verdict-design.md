# 汇金主力三闸门判决条 — 设计说明

**日期：** 2026-08-15
**状态：** 已批准，实现中
**关联：** [2026-07-28 叙事重心调整](./2026-07-28-narrative-signal-first-design.md)、[2026-07-25 占比区间估算](./2026-07-25-huijin-percentage-range-estimate-design.md)

## 背景

看板已有份额流向、占比区间估算和 0AMV，但用户仍会把估算水平值或主线面板误读成「汇金意图」。日频数据没有持有人身份，只能做假设检验。

领域先验（既有估算设计）：这类规模最大的宽基 ETF，**大额**申赎其他持有人很少做。小波动当噪声；大、同向、持续才打开汇金先验。

## 目标

在摘要卡与数据质量条下方增加独立「主力判决」条：

- 四档：`可采信` / `弱支持` / `无法判断` / `更像其他资金`
- 标出三道闸门通过或失败原因
- 仅在可采信或弱支持时给一句意图约束
- 文案禁止「汇金买入 / 卖出」

## 不做

- 不改抓取、估算公式、CSV、主线判定
- 不上 0–100 分数（假精度）
- 不判套利（没有折溢价数据）
- 不把 KDJ / MACD / 主线面板接入判决

## 第 1 节：输入

纯函数，不读全局。从现有快照收集：

| 字段 | 来源 |
|------|------|
| 是否有汇金披露 | `latestHuijin != null` |
| 最新流向 / 连续天数 / 5 日份额变化率 | `huijinEstimateHistory` 最后一个 `shareTrend != null` 的点 |
| 5 日价格变化率 | `navHistory` 累计净值，末点相对前 5 个点；无累计净值时退回单位净值 |
| 低分辨 | 最近 `anchored` 点的 `estimateRangeYi` |
| 0AMV 环境 | `marketActiveCapHistory` 末点相对 `referenceMaYi` |

## 第 2 节：三道闸门

### 闸门 1 对象

通过：至少 1 只 ETF 有汇金披露，且至少 1 只有效日频流向。
失败 → 综合档固定为 `无法判断`。结构闸仍可计算供对照，但不升级档位。

### 闸门 2 结构

多数定义与 `aggregateShareSignals` 相同：某一侧严格大于另一侧且严格大于平坦数。

- **强**：有多数，非平坦最长连续 ≥ 3 日且方向等于多数，且（若存在 5 日变化率）绝对值最大者的符号与多数同向。
- **弱**：有多数但连续不足 3 日；或最长连续 / 5 日幅度与多数冲突；或只有一侧在动且连续 ≥ 3 日（单腿，覆盖面不够）。
- **未过**：无多数，且构不成单腿。

连续天数门槛 `3` 是描述性取值，不是回测标定。

**单腿澄清**：弱支持第三条的「只有一侧在动且连续 ≥ 3 日」指**无多数时**的单侧持续（有动腿但构不成多数）；若多数已在位（如 4 流入 + 1 平），多数判定优先，走强/弱主路径而非单腿。实现见 `singleLegStructure`：仅在无多数时调用，且由 `strongInflow` 测试钉死。

### 闸门 3 替代解释

只在结构未过（混合流向）时才可能判「其他资金」：

- 绝对值最大的两只 5 日份额变化率符号相反，且两侧绝对值都 ≥ 2%（描述性下限，避免日常小幅混合被判成再平衡）；或
- 流入侧与流出侧都有连续 ≥ 2 日

否则记为「未排掉」，综合档 `无法判断`。
结构为强或弱时，本闸记为通过（未见对倒腿）。没有折溢价，不输出「更像套利」。

### 综合

1. 对象失败 → `无法判断`
2. 替代解释 = 其他资金 → `更像其他资金`
3. 结构未过 → `无法判断`
4. 结构强 → `可采信`
5. 结构弱 → `弱支持`

低分辨、份额日期不一致只进提示，不降档。

## 第 3 节：意图句

仅 `可采信` / `弱支持`。价格取有 5 日净值变化的 ETF 等权平均；0AMV 有参考线则比较末值，否则环境未知。

| 流向 | 5 日价格 | 0AMV | 句子 |
|------|----------|------|------|
| 流入 | ≤ 0 | 任意 | 更像托底/接飞刀 |
| 流入 | > 0 | 偏强 | 更像加仓或抬流动性 |
| 流入 | > 0 | 偏弱/未知 | 更像加仓，环境未确认 |
| 流出 | > 0 | 任意 | 更像逢高减磅 |
| 流出 | ≤ 0 | 偏弱 | 更像撤离 |
| 流出 | ≤ 0 | 偏强/未知 | 更像减仓，环境未确认 |

缺价格对照则不编意图。`更像其他资金` 固定写「更像风格再平衡，不输出单一意图」。

## 第 4 节：界面

`ForceVerdictPanel` 插在 `DataQualityBar` 与「汇金持仓趋势」之间，复用 insight 扫读结构：

- 主数字：四档之一（颜色只作辅助：流入青绿 / 流出红 / 弱支持金 / 无法判断灰 / 其他资金紫）
- 三格闸门：对象 / 结构 / 替代解释
- 意图句、提示、固定免责：`不能识别持有人 · 只描述份额结构 · 不构成投资建议`

文字必须自解释，颜色不是唯一编码。

## 第 4.5 节：主力简报（forceBriefing，后补）

判决条定档，简报把同一结论展开成可扫读短评。两者同屏时必须口径一致，因此 `composeForceBriefing` 内部直接调用 `judgeHuijinForce`，不复制判决逻辑；`meanPricePct` / `countTrends` 等共享口径从 `forceVerdict.ts` 导出复用。

**首屏摆放**：`ForceBriefingPanel` 位于 `SummaryCards` 之上（`src/App.vue`），理由是简报一句话即可回答「今天篮子整体在干什么」，先给结论再给摘要卡数字。这与「signal-first 叙事」方向一致；若首屏拥挤可下移至判决条之后，不改变数据口径。

**安静阈值**：`QUIET_ABS_PCT_5D = 3`、`QUIET_CONSECUTIVE_DAYS = 3`——5 日份额变化绝对值 < 3% 且连续 < 3 日视为「几乎没动」，只进 `XX、YY 几乎没动` 一句，不展开。与闸门的 `MIN_*` 常量同为描述性取值，非回测标定。

**金额换算**：`capitalYi = (lastSharesYi - sharesYi5dAgo) × quotePrice`，无行情价或份额缺口时回退用 5 日变化率排序，不编造金额。

**文案约束**：继承判决条全部禁令（禁止「汇金买入/卖出」），并由 `forceBriefing.test.ts` 的 `not.toMatch` 断言钉死。

## 第 5 节：测试与验证

- `forceVerdict.test.ts`：空输入、无披露、多数连续、单腿、方向冲突、对倒 5 日、两侧持续、对象失败优先于其他资金、意图对照表
- `forceVerdictCollect.test.ts`：从快照取末日流向、5 日净值、低分辨
- `bun test`、`bun run build`

# 汇金持仓看板叙事重心调整：信号为主、估算值降级 — 设计说明

**日期：** 2026-07-28
**状态：** 已批准，待实现
**关联：** [2026-07-25 占比区间估算设计](./2026-07-25-huijin-percentage-range-estimate-design.md)

## 背景

全面体检确认计算层准确、口径自洽。但估算"水平值"（如"估算合计 1402 亿"）存在三个叙事问题：

1. 下界触底后"失忆"（clamp 到 0 后重新累加），水平值缺乏清晰物理含义。
2. 2/3 偏向下界的权重在下界贴近 0 时实际由上界主导，设计意图与效果脱节。
3. 单锚点（2025-12-31）已漂 7 个月，水平值偏差不可控。

而份额信号（流向、连续天数、5 日变化率）是实打实的交易所数据，不依赖任何汇金假设，信息量更可靠。

**决策**：降级估算值为次要参考，份额信号成为界面主角。估算值保留但明确标注"区间中值、仅供方向参考"。

## 第 1 节：聚合信号卡（SummaryCards.vue）

替换当前第 2 张卡"汇金估算合计持仓"的位置。

### 数据来源

各 ETF 最新 anchored 点的 `shareTrend` / `consecutiveDays` / `shareChangePct5d`（已有字段，无需改后端）。

### 卡片结构

- **label**：`份额信号（汇金方向参考）`
- **主数字**：有锚点 ETF 中当日流向占比
  - inflow 占多数：`4/5 只净流入`
  - outflow 占多数：`3/5 只净流出`
  - 混合（无明确多数）：`2入/2出/1平`
  - 无锚点：`—`
- **副文案**（两行）：
  - 第 1 行：`consecutiveDays` 最大且 shareTrend ≠ flat 的 ETF → `{类别} 连续{N}日{净流入/净流出}`
  - 第 2 行：`|shareChangePct5d|` 最大的 ETF → `{类别} 5日 {+/-X.X}%`
  - 无锚点时：`无汇金披露锚点，暂不生成信号`
- **accent 色**：inflow 多数 → teal；outflow 多数 → red（`#f07178`）；混合 → orange

### 估算合计卡降级

- 位置：从第 2 位移到第 4 位（0AMV 卡之后）
- label：`汇金估算持仓（区间中值）`
- sub：保留"纳入 N/6 只 · 估算日 …"，追加"· 仅供方向参考"
- accent：保持 orange

## 第 2 节：EtfTable 列重排（EtfTable.vue）

### 当前列序

类别 / 代码 / 名称 / 现价 / 涨跌 / 份额日期 / 基金总份额 / 净份额变化 / 基金规模 / 报告期 / 汇金份额 / 汇金占比 / 最近披露估值 / 估算持仓 / 份额趋势

### 调整后列序

类别 / 代码 / 名称 / 现价 / 涨跌 / 份额日期 / 基金总份额 / 净份额变化 / **份额趋势** / 基金规模 / 报告期 / 汇金份额 / 汇金占比 / 最近披露估值 / 估算持仓

变化：
- "份额趋势"从第 15 列前移到第 9 列（紧跟"净份额变化"）
- "估算持仓"退到末列
- 列内容不变（箭头 + 连续天数 + 5 日变化率）

### 表头 tooltip

"份额趋势"列 `<th>` 加 `title="基于交易所总份额流向，供判断汇金方向参考，不代表汇金实际操作"`。

## 第 3 节：EtfDetail 标签调整（EtfDetail.vue）

规模区两个 KPI标签：
- "汇金当前持仓" → **"估算持仓（参考）"**
- "汇金当前占比" → **"估算占比（参考）"**

保留 ≈ 前缀和 estimate-note 文案不变。头部 KPI 区（披露值）不动。

## 第 4 节：趋势图说明文案（App.vue panel-head）

HuijinTrendChart 所在 panel 的 muted 副标题改为：

> 虚线为占比区间估算（仅供方向参考）；次轴细线为份额 5 日变化率，是判断汇金方向的主要信号

图表组件本身（series/tooltip/次轴）不动。

- 不改 README 口径声明

- 不改 HuijinTrendChart.vue 组件内部（仅改 App.vue 中的 panel-head 文案）

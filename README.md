# 中央汇金 · 宽基 ETF 持仓监控

Vue 3 + Vite + Bun + ECharts 看板：按类别自动选取**市值最大**的宽基 ETF，基于公开的基金年报/半年报「十大持有人」监控**中央汇金**持仓，并展示 ETF 份额与沪深市场 0AMV 活筹估算趋势。

东财 0AMV 日线不可用时，可显式启用 Tushare 备用源：设置 `TUSHARE_TOKEN` 与 `TUSHARE_FALLBACK=1`。
Tushare `index_daily` 需要分别请求三只指数，且免费额度可能限制为每小时一次，因此默认不自动启用；额度不足时程序会继续使用最新快照或上次有效数据，不会用成交量冒充成交额。

中信期货会员股指期货多空持仓默认抓**中金所官网**（无需任何 token）。这条链路依赖本机 **Python + `akshare`**（`pip install akshare`）：抓取脚本会调用 `python scripts/sources/cffex_citic.py`。若本机 `python` 不在 Bun 的 PATH 解析范围，可设 `CITIC_PYTHON` 指向解释器完整路径。未装 Python/akshare 时该数据源会优雅降级（面板显示“未接入数据源”），不影响其它模块。设置 `TUSHARE_TOKEN` 时改为 Tushare `fut_holding`（需约 2000 积分）。

中金所链路是**增量**的：有缓存时只从上次最后日期的次日抓到现在（加 1 天冗余），与缓存合并后重算增减；无缓存才从 2024-01-01 全量回填一次（约 5–6 分钟）。因此首次回填慢、之后每次仅数秒到数十秒。

东方财富历史日线接口不可用时，抓取脚本会改用同源 `stock/get` 最新指数快照，
在已有 0AMV 历史末尾补算最新交易日，避免日线接口的路径级封禁让序列永久停滞。快照会记录实际来源、截止日期与是否为临时快照；历史接口返回空序列时也会继续进入备用链。

> 汇金持仓一般在**年报/半年报**披露，不是实时持仓。披露估值 = 披露份额 × 报告日附近单位净值。新浪接口若对多个历史日期返回相同快照，抓取脚本会去重并只保留一份已验证披露。最近披露期之后按**占比区间**口径生成估算序列：下界从最近披露汇金份额起逐日累加交易所总份额净变化（份额变动全归因汇金，假设大额赎回/申购主要由汇金进行）；上界维持最近披露的汇金占比不变（汇金被动等比例稀释）；展示值取区间加权（下界 2/3 + 上界 1/3）。实际汇金份额落在区间内。估算不代表汇金实际持仓。

## 快速开始

```bash
# 安装依赖
bun install

# 抓取并缓存公开数据 → data/dashboard.json & public/dashboard.json（紧凑 JSON）
bun run fetch

# 启动 API（可选，支持 /api/dashboard 与后台刷新）
bun run server

# 另开终端启动前端
bun run dev
```

浏览器打开 Vite 提示的地址（默认 http://127.0.0.1:5173 ）。

看板还提供：

- 数据质量状态带：区分行情、官方日份额、汇金披露、缓存沿用和未知区间
- 0AMV 图表中的持有人报告期事件标记，以及报告期后第 5/20 个交易日的变化对比；非报告期不生成汇金持仓事件
- 参考线穿越历史统计：记录 0AMV 上穿/下穿 5 日参考线的样本数，并统计已完成 +20 个交易日窗口的方向一致率
- ETF 表格状态筛选、排序，以及 ETF 快照和 0AMV 日线 CSV 导出
- ETF 份额变化趋势使用 ECharts `time` 时间轴，优先绘制交易所官方日频总份额；首次回填至 2024-01-01（约 380 个交易日），之后增量更新并复查最近 5 个交易日

仅前端静态预览（已有 `public/dashboard.json`）：

```bash
bun run dev
```

## GitHub Pages 自动更新

仓库包含 `.github/workflows/deploy-pages.yml`：GitHub Actions 会在交易日北京时间 22:00（UTC 14:00）抓取公开数据、执行构建与审计，并发布到 GitHub Pages；也可以在 Actions 页面手动运行 `workflow_dispatch`。选 22:00 是因为上交所/深交所 ETF T 日总份额通常要到 T 日晚间才发布，过早抓取会拿不到当日“份额日期”。定时任务会尝试把最新 `data/dashboard.json` 和 `public/dashboard.json` 保存回默认分支，作为下一次抓取的缓存快照；偶有交易所发布更晚导致当日未抓到时，下一次抓取会自动补齐。

首次使用时，在仓库 Settings → Pages 将 Source 设为 **GitHub Actions**。项目站点地址通常是 `https://<用户名>.github.io/<仓库名>/`；Vite 会根据 Actions 的仓库名自动设置子路径，用户站点仓库 `<用户名>.github.io` 则使用根路径。

GitHub Pages 只提供静态文件，不运行本项目的 Bun API 服务。因此 Pages 上不会显示“刷新公开数据”按钮，数据由 Actions 定时或手动工作流更新；本地运行 `bun run server` 时仍支持页面内刷新。

## 0AMV 活跃市值口径

- **净资产**：定期报告披露的基金净资产（亿元）
- **汇金披露估值**：报告期汇金合计份额 × 报告日附近单位净值
- **0AMV（活筹指数）**：按公开近似公式 `SMA(沪深两市成交额, 10, 1) × 中证全指收盘 / MA(REF(中证全指收盘, 1), 5)` 计算，结果按亿元展示
- **沪深两市成交额**：上证综指 `000001` 与深证成指 `399001` 的日成交额之和；不再使用中证全指成分股成交额冒充完整沪深市场成交额
- 0AMV 是独立的沪深市场日频估算序列，不使用 ETF 份额、基金净资产或六只 ETF 的合计规模
- 指南针原版算法未公开，因此绝对值仅为公开公式估算，主要用于观察方向和趋势；指标定义参见[指南针 0AMV 说明](https://www.compass.cn/shownews.php?nid=33751625)
- 参考线穿越历史只做描述统计：上穿后的“为正”与下穿后的“为负”均以穿越日后的第 20 个交易日为窗口，未完成窗口不纳入比例；该统计不代表未来概率或投资胜率，也不是扣除成本后的回测
- 汇金持仓趋势展示两类数据点：① 十大持有人报告期正式披露点（实线）；② 最后披露期之后的占比区间估算点（虚线，明确标注）。下界假设份额变动全归因汇金，上界假设汇金占比不变，**展示值为区间加权（下界 2/3 + 上界 1/3），不是中值**；表格与 tooltip 同时给出 floor~ceil。当区间宽度 ≥ 当日总份额 30% 时标记「低分辨」，点估计不可依赖。
- 日频净份额变化按“当日交易所总份额 - 上一交易日交易所总份额”计算，不把二级市场成交量当作申赎，也不声称能够拆分申购、赎回毛额。
- 日频基金规模由“交易所总份额 × 当日附近单位净值”估算；定期报告日期仍优先采用正式披露净资产。
- ETF 份额变化无法识别持有人身份，因此只作为**总份额异常/流向**信号，不表述为汇金买卖；份额锚定估算仅基于区间假设，无汇金披露的 ETF 不生成估算值。

## 主力判决

打开看板先看到「主力简报」：用同一套三闸门规则把流向、去向和意图收成一段短评，不是模型推理。文案禁止写成「汇金买入 / 卖出」，篮子外资金去向标为未知。

第一屏在数据质量条下方继续给出四档描述性结论：`可采信` / `弱支持` / `无法判断` / `更像其他资金`。

- **对象**：至少一只 ETF 有汇金披露，且存在日频总份额流向。过不了这一关，后面只作对照，不升级档位。
- **结构**：多数同向且连续 ≥ 3 日、5 日份额变化率不打架，才算强；单腿或连续不足则为弱。
- **替代解释**：混合流向里，两侧都持续，或两只最大 5 日变化率反向且幅度都 ≥ 2%，记为更像其他资金（再平衡），不识别套利。
- 可采信 / 弱支持时才用 5 日净值与 0AMV 参考线写一句意图约束。低分辨与份额日期不一致只提示，不降档。

该判决**不能识别持有人**，只描述宽基 ETF 总份额结构，不构成投资依据。连续天数与 2% 幅度下限是描述性取值，未经收益标定。

## 散户情绪反向

主力判决下方给出「散户情绪反向」面板，用六大宽基 ETF 的**总份额净申购率**（交易所日频净变化 / 前一日总份额）作为非汇金资金的申赎情绪代理：

- **情绪方向**：各 ETF 5 日累计净申购率 ±2% 多数投票（追涨申购 / 杀跌赎回 / 平静）。
- **申赎温度**：最新日净申购率在 250 日回看内的分位取中位数，≥ 85 为高热、≤ 15 为冰点，中间按 65 / 35 分档。
- **交投温度**：场内换手率（当日成交量/基金总份额）在 250 日回看内的分位取中位数，≥ 85 亢奋、≤ 15 低迷。换手反映二级市场「倒手频率」，与申赎（一级市场进出场）互补。历史自接入日起积累，不足 30 日显示「样本不足」。直连 tdx 后可一次性回填历史（`node-tdx-market`，无需服务，见 [`docs/tdx-integration.md`](docs/tdx-integration.md)）。
- **杠杆温度**：融资买入额占沪深成交额比率在 250 日回看内的分位，≥ 85 杠杆过热、≤ 15 降杠杆；另展示融资余额 5 日变化率。两融以个人投资者为主，是散户杠杆情绪的直接读数；但为全市场口径，无法拆分到宽基成分。
- **其他资金存量**：总份额 − 汇金估算点估计（亿份），仅对有汇金披露的 ETF 展示与合计；估算区间过宽时降为提示。
- **反向象限**：情绪方向 × 汇金估算份额多数方向交叉。散户杀跌 + 汇金流入 = 对手盘吸纳（经典底部组合）；散户追涨 + 温度偏热且汇金无多数方向 = 拥挤警戒；两边同向 = 无反向信息；矛盾或量级不足 = 无法判断。

> 「非汇金资金」含机构、游资与散户，散户只是主要成分之一。反向解读是描述性叙事，不是因果预测，不构成投资建议。科创50 无汇金披露，仅参与总份额口径。

### 历史标定结论（2026-08-17，`bun run calibrate:retail`）

- **杠杆温度**：融资买入占比 0-20 分位（冰点）组未来 20 日平均 **-0.63%**、上涨率 47.5%，显著差于 20-40 分位组的 +1.42%——**冰点端有（顺向）信号：杠杆冰点时后市更弱**；80-100 分位（过热）组 +0.15% 与中段无显著差异，高温端反向不成立。样本 1330 日（2020-01 → 2026-08）。
- **申赎温度**：净申购率各分位组未来 20 日收益差异均在噪音区（顶底差 +0.58pp < 2×标准误；363 样本，2024-01 起），**无显著预测力，仅作状态描述**。
- **交投温度**：换手历史积累中（需 ≥ 270 日），待积累后纳入标定。

样本覆盖单一市场周期且未做多重检验校正，以上为描述性统计，不构成投资建议。

## 主线结构判定

判断一段行情是否存在「主线」，需要三项横截面度量同时成立，缺一不可：

- **分化度**：各板块窗口累计收益的样本标准差，取过去约两年的历史分位。分位过低说明齐涨齐跌，无主线可言。
- **持续性**：前半窗与后半窗收益排名的 Spearman 秩相关。分化度高但持续性低，是高低切轮动而非主线——分化只是必要条件。
- **龙头日超额胜率**：窗口收益第一的板块相对等权平均的日超额为正的交易日占比。比例过低说明涨幅集中于少数交易日，是脉冲而非台阶式上行。窗口累计收益为负时，展示称「相对最强」而非「龙头」。

同时在 5 / 20 / 60 三个窗口评估；**综合结论取 20 日主观察窗**（与 `bun run calibrate` 的历史检验口径一致），5 / 60 日仅作分窗对照（5 日半窗过短、秩相关噪声大，面板标为高噪声）。短窗 Spearman 噪声大，若对三窗取最弱，综合「有主线」触发率会被压到近 0，与单窗检验错位。辅窗与主窗判定不一致时，面板会给出分歧提示（不降级综合结论）。另输出**跨窗领先一致性**（20 与 60 日领先板块是否同一）：N 较小时单窗秩相关噪音大，这是更稳的描述性旁证，同样不改综合结论。风格主线使用 ETF 累计净值，避免分红除息导致普通净值短暂下跌并制造假轮动。

| 口径 | 横截面 | 能识别 |
|------|--------|--------|
| 风格主线 | 6 只宽基 ETF 累计净值 | 大小盘、成长价值 |
| 题材主线 | 申万二级行业板块（东财 BK04-BK10 段，74 个） | 半导体、光伏、创新药等 |

行业板块取申万二级而非一级：一级会把题材平均掉（「电子」会稀释半导体行情）。东财板块代码分三段，每段各自完整覆盖一次全市场（三段市值合计各约占 1/3），只取二级段可保证板块互斥不重叠——重叠板块同涨同跌会人为压低分化度。单次抓取偶有个别板块连接失败，会被按覆盖率剔除，因此实际入库数量可能略少于 74。

### 历史检验结论

`bun run calibrate` 对两个口径逐日回溯判定，再看龙头其后 20 日相对等权平均的超额收益。
**两个口径结论相反**：

**风格口径（6 只宽基累计净值，2020-09 起 1404 个交易日）——负面：**

| 判定 | 样本 | 龙头其后 20 日超额 | 龙头跑赢率 |
|------|------|-------------------|-----------|
| 有主线 | 306 | **-0.21%** | 47.1% |
| 弱主线 | 48 | +1.04% | 56.3% |
| 轮动无主线 | 261 | -0.15% | 50.2% |
| 无主线 | 519 | -0.53% | 42.0% |

- 判为「有主线」时龙头其后仍略微跑输，前视拉长到 120 日约 -1.9%、跑赢率 33.8%。这仍不支持把该判定当作预测信号。
- 判为「有主线」后 20 日仍为「有主线」的比例（24.8%）**低于**无条件基础比例（约 27.1%）——连状态本身都不延续。
- 扫描三项门槛的全部取值，没有任何组合能让超额稳定转正；门槛变化后的结果方向不稳定，不能据此调参。
- 一个可能的原因：N=6 时 ρ=0.3 在统计上根本不显著（p≈0.56），持续性度量本身即噪音。风格收益序列现在使用累计净值，以避免 ETF 分红除息造成虚假的相对弱势。

**题材口径（72 只申万二级行业，2024-02 起 600 个交易日）——正面但样本不足：**

| 判定 | 样本 | 龙头其后 20 日超额 | 龙头跑赢率 |
|------|------|-------------------|-----------|
| 有主线 | 46 | **+3.29%** | 50.0% |
| 轮动无主线 | 211 | -3.83% | 23.7% |
| 无主线 | 73 | -0.27% | 37.0% |

- 方向与风格口径相反，且三项门槛越高收益越单调改善（如抬高 leaderEdge 时超额可进一步上升）。这与「行业动量真实存在、风格轮动在月度尺度反转」的经典结论一致。
- **但阈值刻意未上调**：可用行情仅 600 个交易日，相邻观察点共享 19/20 的窗口，约 46 个 mainline 样本折算后只有约 2 个独立事件；在这种样本上按收益调参几乎必然过拟合。前视窗口敏感性也不稳定（20 日 +3.29%、60 日 -4.30%、120 日 +1.87%），不具备可依赖的形状。

两个口径的阈值因此都维持描述性取值。该判定**只用于描述当下市场结构，不构成投资依据**；风格口径未显示已验证的预测力，题材口径的正向结果尚不足以确认。等行业历史积累更长后应重跑标定。

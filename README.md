# 中央汇金 · 宽基 ETF 持仓监控

Vue 3 + Vite + Bun + ECharts 看板：按类别自动选取**市值最大**的宽基 ETF，基于公开的基金年报/半年报「十大持有人」监控**中央汇金**持仓，并展示 ETF 份额与沪深市场 0AMV 活筹估算趋势。

## 监控范围

| 类别 | 说明 |
|------|------|
| 上证50 | 取该主题规模最大 ETF |
| 沪深300 | 同上 |
| 中证500 | 同上 |
| 中证1000 | 同上 |
| 创业板 | 同上 |
| 科创50 | 同上 |

每次抓取都会扫描东方财富场内 ETF 行情接口返回的完整分页（当前快照为 1548 只），先按名称匹配直接跟踪对应基础指数的 ETF，再按 `f20` 总市值降序选出该类别最大者。接口异常时才使用配置候选代码和规模披露作为兜底，不将其作为正常排序口径。

汇金系识别名称：

- 中央汇金投资有限责任公司
- 中央汇金资产管理有限责任公司
- 名称中含「中央汇金」的资管计划

## 数据来源（公开接口）

| 数据 | 来源 |
|------|------|
| 十大持有人 | 新浪财经 `FundPageInfoService.tabsdcyr` |
| 规模变动 / 净资产 | 天天基金 `FundArchivesDatas?type=gmbd` |
| 单位净值 | 东方财富 `api.fund.eastmoney.com/f10/lsjz` |
| ETF 市值/行情 | 东方财富 `push2` clist |
| 0AMV 价格代理 | 东方财富中证全指 `000985` 日线 |
| 0AMV 成交额输入 | 东方财富上证综指 `000001` + 深证成指 `399001` 日成交额 |

> 汇金持仓一般在**年报/半年报**披露，不是实时持仓。估算市值 = 披露份额 × 报告日附近单位净值。新浪接口若对多个历史日期返回相同快照，抓取脚本会去重并只保留一份已验证披露。

## 快速开始

```bash
# 安装依赖
bun install

# 抓取并缓存公开数据 → data/dashboard.json & public/dashboard.json
bun run fetch

# 启动 API（可选，支持 /api/dashboard 与后台刷新）
bun run server

# 另开终端启动前端
bun run dev
```

浏览器打开 Vite 提示的地址（默认 http://127.0.0.1:5173 ）。

看板还提供：

- 数据质量状态带：区分行情、规模披露、汇金披露、缓存沿用和估算可用性
- 0AMV 图表中的持有人报告期事件标记，以及报告期后第 5/20 个交易日的变化对比；估算规模期不会伪装成公告事件
- 参考线穿越历史统计：记录 0AMV 上穿/下穿 5 日参考线的样本数，并统计已完成 +20 个交易日窗口的方向一致率
- ETF 表格状态筛选、排序，以及 ETF 快照和 0AMV 日线 CSV 导出
- ETF 份额变化趋势使用 ECharts `time` 时间轴，直接绘制规模披露日期；不把季度/半年披露点按等间距类别轴连接，也不使用平滑线制造中间数据

仅前端静态预览（已有 `public/dashboard.json`）：

```bash
bun run dev
```

## GitHub Pages 自动更新

仓库包含 `.github/workflows/deploy-pages.yml`：GitHub Actions 会在交易日北京时间 16:30（UTC 08:30）抓取公开数据、执行构建与审计，并发布到 GitHub Pages；也可以在 Actions 页面手动运行 `workflow_dispatch`。定时任务会尝试把最新 `data/dashboard.json` 和 `public/dashboard.json` 保存回默认分支，作为下一次抓取的缓存快照。

首次使用时，在仓库 Settings → Pages 将 Source 设为 **GitHub Actions**。项目站点地址通常是 `https://<用户名>.github.io/<仓库名>/`；Vite 会根据 Actions 的仓库名自动设置子路径，用户站点仓库 `<用户名>.github.io` 则使用根路径。

GitHub Pages 只提供静态文件，不运行本项目的 Bun API 服务。因此 Pages 上不会显示“刷新公开数据”按钮，数据由 Actions 定时或手动工作流更新；本地运行 `bun run server` 时仍支持页面内刷新。

## 0AMV 活跃市值口径

- **净资产**：定期报告披露的基金净资产（亿元）
- **汇金估算市值**：汇金合计份额 × 对应规模期附近单位净值
- **0AMV（活筹指数）**：按公开近似公式 `SMA(沪深两市成交额, 10, 1) × 中证全指收盘 / MA(REF(中证全指收盘, 1), 5)` 计算，结果按亿元展示
- **沪深两市成交额**：上证综指 `000001` 与深证成指 `399001` 的日成交额之和；不再使用中证全指成分股成交额冒充完整沪深市场成交额
- 0AMV 是独立的沪深市场日频估算序列，不使用 ETF 份额、基金净资产或六只 ETF 的合计规模
- 指南针原版算法未公开，因此绝对值仅为公开公式估算，主要用于观察方向和趋势；指标定义参见[指南针 0AMV 说明](https://www.compass.cn/shownews.php?nid=33751625)
- 参考线穿越历史只做描述统计：上穿后的“为正”与下穿后的“为负”均以穿越日后的第 20 个交易日为窗口，未完成窗口不纳入比例；该统计不代表未来概率或投资胜率，也不是扣除成本后的回测
- 汇金持仓估算分层处理：同日使用十大持有人披露；两个披露期之间按持仓份额线性插值；披露期之后优先沿用最近披露份额，若该份额超过本期基金总份额，则按“最近披露汇金占比 × 本期总份额”锚定估算，再乘规模期单位净值计算市值。
- 上述锚定估算只用于在定期报告之间形成参考值，不代表实时持仓；没有任何汇金持仓披露的 ETF 不生成估算值。
